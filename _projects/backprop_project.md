I completed this project in January of 2024 as I was just getting into Neural Networks and programming.
I had done some stuff in PyTorch, but that felt more like web development than anything else, and I wanted 
to see exactly how what I was using actually worked. I found and followed [this great tutorial](https://www.youtube.com/watch?v=LA4I3cWkp1E), 
which I recommend for anybody starting to get into ML.

This was a very impactful project, because it made me realize I find the theory and low level implementation 
of learning algorithms fun. This later helped guide me to my future research area of math and statistically 
inspired machine learning, because I found that I like the process of: 1. Gain a mathematical insight. -> 
2. Use that insight to design a learning algorithm. -> 3. Implement and test that learning algorithm.
