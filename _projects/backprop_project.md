I completed this project in January of 2024 as I was just getting into Neural Networks and programming.
I had worked through a basic autoencoder and VAE tutorial in PyTorch, but I wanted to see exactly how what I was using 
actually worked. I found and followed [this great tutorial](https://www.youtube.com/watch?v=LA4I3cWkp1E), 
which I recommend for anybody getting into ML.

This was a very impactful project, because it helped me to realize later that I find the theory and low level implementation 
details of learning algorithms fun. This eventually helped guide me to my future research area of math and statistically 
inspired machine learning, because I found that I like the process of: 1. Gaining a mathematical insight. -> 
2. Using that insight to design or improve a learning algorithm. -> 3. Implementing and testing that learning algorithm.
