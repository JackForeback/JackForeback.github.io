I did this project for my Linear Algebra 3 class, one of my favorite classes I have ever taken along with Graph 
Theory. It was taught by [Dr. David Austin](https://davidaustinm.github.io/) who has some amazing, open-access 
Linear Algebra textbooks online. I mostly did this project to satisfy my own curiosity, because I had heard of 
KANs years ago, but had no idea why I had never heard of them again. 

To get the full story read my paper below. I also had claude make a cool little interactive tool that should 
hopefully illustrate the idea of a composition of basis functions. I loved this project not only because it
satisfied my curiosity, but because the linear algebraic perspective on neural networks and machine learning 
is beautiful.
